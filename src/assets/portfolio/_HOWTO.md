# Как добавить объект в портфолио (самостоятельно)

## 1. Папка объекта
У каждого объекта — своя папка внутри `src/assets/portfolio/`, названная как его `slug`
(латиницей, из `src/data/projects.ts`). Например: `kvartira-72-gorki`.

## 2. Фотографии
Кладёте фото прямо в папку объекта. Форматы: jpg, jpeg, png, webp.
Имена — как удобно, но лучше короткие: `1.jpg`, `2.jpg`, `kuhnya.jpg` и т.п.

## 3. Описание по зонам — файл `description.md`
В папке объекта создаёте текстовый файл с именем **строго** `description.md`.
Пишете зоны заголовками, под каждым — фото и текст. Пример:

```markdown
## Прихожая

![Прихожая](./1.jpg)

Текст про прихожую: материалы, цвета, решения…

## Кухня-гостиная

![Кухня-гостиная](./2.jpg)

Текст про кухню-гостиную…
```

Правила:
- `## Название` — заголовок зоны (две решётки и пробел).
- `![любой текст](./имя-файла.jpg)` — фото. **Путь всегда начинается с `./`** и указывает
  имя файла, который лежит в этой же папке. Имя должно совпадать точно (регистр важен).
- Обычный текст под фото — это описание. Пустая строка отделяет абзацы.
- Фото и текст можно менять местами (сначала текст, потом фото — как хотите).

### Несколько фото в один ряд
Пишете строки с фото **подряд, без пустой строки между ними** — они встанут в один ряд
одинаковой высоты и сами перенесутся на узком экране:

```markdown
![Кухня 1](./3.jpg)
![Кухня 2](./4.jpg)
![Кухня 3](./5.jpg)
```

А если между фото оставить **пустую строку** — каждое станет отдельным, во всю ширину:

```markdown
![Большое фото](./3.jpg)

![Ещё одно большое фото](./4.jpg)
```

## 4. Проверка
- Если `description.md` есть — на странице объекта показываются зоны (фото + текст).
- Если файла нет — показывается простая галерея из всех фото папки.
- Если в `![](./x.jpg)` указать имя файла, которого нет в папке — сборка сообщит об ошибке
  (в режиме `npm run dev` это видно в браузере). Просто исправьте имя.

## 5. Новый объект целиком
1. В `src/data/projects.ts` добавьте запись: `slug`, `title`, `area`, `rooms`, `district`,
   `complex`, `style`, `format`, `duration`, `summary`.
2. Создайте папку `src/assets/portfolio/<slug>/`, положите фото и `description.md`.

Пример готового объекта — папка `kvartira-72-gorki` (фото + `description.md`).
